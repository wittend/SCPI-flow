### Objectives:

### Create a visual simulation of a two input oscilloscope.

- Application framework: Deno.js,
- Use vendored assets and dependencies.
- Allow for both CLI and GUI applications.
- Allow for both offline and local-network only operation.

#### Create a visual simulation of a two input oscilloscope.

- An example to use: https://siglentna.com/digital-oscilloscopes/sds1000x-u/
- A Programming reference can include:
  .assets/SDS1000-SeriesSDS2000XSDS2000X-E_ProgrammingGuide_EN02E.pdf
- The scope should be able to display two signals.
- The scope should be able to display a vertical and horizontal grid.
- The scope should be able to display a vertical and horizontal scale.
- The scope should be able to display a vertical and horizontal offset.
- The scope should be able to display a vertical and horizontal zoom.
- The scope should be able to display a vertical and horizontal pan.
- The scope should be able to display a vertical and horizontal cursor.
- The scope should be able to display a vertical and horizontal crosshair.
- The scope should be able to display a vertical and horizontal ruler.
- The scope should be able to display a vertical and horizontal legend.
- The scope should be able to display a vertical and horizontal title.
- The scope should be able to display a vertical and horizontal color scale.
- The scope should be able to display a vertical and horizontal color legend.

### Input:

#### The simulation must be able to create and present simulated data that can be read by the SCPI interface.

- It needs to be able to generate a sine wave of a given frequency.
- It needs to be able to generate a square wave of a given frequency.
- It needs to be able to generate a triangle wave of a given frequency.
- It needs to be able to generate a sawtooth wave of a given frequency.
- It needs to be able to manipulate amplitude, frequency, phase, and offset.
- It needs to be able to manipulate the scale,

#### User input:

- This simulation must respond to user input.

#### SCPI interface:

- The simulation must be able to respond to SCPI commands.
- The simulation must be able to report SCPI status.
- The simulation must be able to report SCPI errors.
- The simulation must be able to report SCPI measurements.
